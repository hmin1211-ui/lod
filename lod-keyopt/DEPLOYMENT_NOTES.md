# 어둠의전설 키세팅 옵티마이저 배포 및 주의사항

## 개요

이 앱은 어둠의전설 `.keysetting` 파일을 비교하고, 선택한 단축키/매크로만 적용 대상 파일로 옮기기 위한 웹 도구입니다.

Vercel 배포판은 서버가 키세팅 파일을 처리하지 않는 정적 웹앱입니다. 사용자가 선택한 폴더와 파일은 브라우저의 File System Access API로 읽고, 분석/검증/병합도 브라우저 메모리 안에서 처리합니다.

## 배포 구조

- 배포 대상 앱: `lod-keyopt`
- 루트 배포 산출물: `vercel-static`
- 키세팅 옵티마이저 경로: `/`
- 기존 계산기 경로: `/calculator`
- 예상 Vercel 프로젝트명: `lod-keyopt`
- 예상 주소: `https://lod-keyopt.vercel.app`

`lod-keyopt.vercel.app` 주소는 Vercel 프로젝트 이름이 `lod-keyopt`이고 해당 이름이 비어 있을 때 사용할 수 있습니다.

## 트래픽과 용량

- 앱 정적 파일 크기: 약 60KB대
- gzip 전송 기준 예상 크기: 약 20KB 이하
- 실제 확인된 `.keysetting` 파일 크기: 약 2.7KB-3.0KB
- 키세팅 파일 분석/병합 트래픽: Vercel로 전송하지 않음
- Vercel 저장공간 사용: HTML/CSS/JS 정적 파일만 사용

현재 구조에서는 Vercel Function을 사용하지 않으므로 Function 호출량, 서버 저장공간, 요청 본문 크기 제한의 영향을 거의 받지 않습니다.

## 중요한 보안/브라우저 제약

브라우저 웹앱은 사용자의 로컬 경로를 직접 읽을 수 없습니다.

불가능한 것:

- `C:\Nexon\Legend of Darkness R\Config` 경로를 입력해서 바로 읽기
- 최초 실행 시 해당 경로를 자동으로 열기
- 선택한 폴더의 전체 `C:\...` 경로 표시
- 배포 시점에 특정 PC의 폴더 핸들을 미리 저장해서 배포

가능한 것:

- 사용자가 `찾아보기`로 직접 Config 폴더 선택
- 선택한 폴더 안의 `.keysetting` 파일 목록 읽기
- 하위 폴더 제외
- 한 번 선택한 폴더 핸들을 브라우저에 저장하고 다음 선택창 시작 위치로 재사용
- 선택한 두 파일만 브라우저 메모리에서 분석

## 기본 폴더 안내

앱 화면에는 다음 기본 위치를 안내 문구로 표시합니다.

```text
C:\Nexon\Legend of Darkness R\Config
```

다만 이 경로는 안내용 텍스트이며, 웹앱이 자동으로 접근할 수 있는 경로 권한은 아닙니다.

## 저장 방식

### 새 키셋팅 생성

병합 결과를 새 `.keysetting` 파일로 다운로드합니다.

가장 안전한 방식입니다. 적용 전에 원본 파일과 적용 대상 파일을 유지할 수 있습니다.

### 적용 대상 파일 덮어쓰기

브라우저가 File System Access API의 쓰기 권한을 허용한 경우에만 동작합니다.

주의사항:

- 브라우저가 추가 권한 확인을 요청할 수 있습니다.
- 일부 브라우저에서는 덮어쓰기가 지원되지 않을 수 있습니다.
- 실수 방지를 위해 먼저 새 파일 생성 방식으로 결과를 확인하는 것이 안전합니다.

## 검증 로직

내보내기 전 `충돌 검증`을 실행해야 저장할 수 있습니다.

검증 대상:

- 선택한 일반 단축키가 적용 대상 파일의 기존 단축키와 중복되는지
- 매크로 복사 시 원본 매크로 실행키가 대상 슬롯으로 이동했을 때 중복되는지
- 매크로 실행키를 사용자가 수정한 경우 그 수정값이 중복되는지

예를 들어 원본 `매크로7-텔깃`의 실행키가 `` ` `` 이고, 적용 대상 파일의 `통합슬롯 버튼13`도 `` ` `` 이면 검증에서 충돌로 막힙니다.

## 매크로 복사 방식

매크로는 원본 슬롯과 대상 슬롯을 분리해서 처리합니다.

예:

```text
원본 매크로7 -> 대상 매크로4
```

이 경우 화면에서 실행키를 수정하면 `매크로7` 행에만 표시됩니다. 실제 내보내기 시점에만 해당 실행키가 대상 파일의 `매크로4` 실행키 위치로 적용됩니다.

## 키 매핑 주의사항

확인된 키는 앱 내부 매핑표에 따라 표시합니다.

특히 `PgDown`은 기존 실측 데이터에는 없었지만 `PgUp`의 인접 코드인 `0x42`로 추가되어 있습니다. 실제 게임에서 다르게 동작하면 추가 실측 후 매핑을 수정해야 합니다.

## 권장 배포 절차

1. Vercel에서 새 프로젝트를 만듭니다.
2. 프로젝트 이름을 `lod-keyopt`로 지정합니다.
3. 저장소 루트는 현재 프로젝트 루트를 사용합니다.
4. `vercel.json`의 설정을 사용합니다.
5. Build Command는 `npm run build`를 사용합니다.
6. Output Directory는 `vercel-static`입니다.
7. 배포 후 `/`에서 키세팅 옵티마이저가 열리는지 확인합니다.
8. `/calculator`에서 기존 계산기가 유지되는지 확인합니다.

## 배포 전 체크리스트

- `lod-keyopt/app.js` 문법 검사 통과
- Vercel 산출물에 `index.html`, `styles.css`, `app.js` 포함
- `/calculator` 산출물 포함
- 실제 `.keysetting` 두 파일 분석 가능
- 매크로 복사 충돌 검증 가능
- 새 키셋팅 다운로드 가능
- 덮어쓰기 동작은 지원 브라우저에서 별도 확인

## 운영 시 안내 문구

사용자에게는 다음 내용을 명확히 안내하는 것이 좋습니다.

- 키세팅 파일은 서버로 전송되지 않습니다.
- 최초 1회는 직접 Config 폴더를 선택해야 합니다.
- 선택한 폴더의 전체 경로는 브라우저 보안 정책상 표시되지 않습니다.
- 덮어쓰기 전에는 새 파일 생성 방식으로 먼저 확인하는 것을 권장합니다.
